# Source code for PiperReader 1.6.5

The complete application source, tests, packaging scripts, and native audio
build recipe are published under the version tag:

https://github.com/Shettima123/PiperReader/tree/v1.6.5

The release page provides the matching application source ZIP and the companion
`PiperReader-1.6.5-dependency-sources.zip` containing dependency source archives,
their SHA-256 hashes, upstream locations, and build/provenance notes:

https://github.com/Shettima123/PiperReader/releases/tag/v1.6.5

These source downloads are available without payment. See `licenses/SOURCES.json`
in an installed or portable copy for the precise dependency source manifest, and
`licenses/INDEX.txt` for license notices. Third-party components retain their own
licenses. The original PiperReader application is AGPL-3.0-only; see LICENSE.

Follow README.md and the native audio build instructions in the application source
to build a modified version. Building requires Windows x64, Python 3.12, the
recorded Python dependencies, Inno Setup, and the documented native build tools.
The application does not restrict replacing its local shared libraries or running
a modified build. Keep a copy of the matching source materials and notices with
any redistributed copy, or provide the required equivalent source access under
the applicable licenses.
